How this is built

Public Play Store data is pulled daily (google-play-scraper). Each new review is labelled once — journey stage, who would fix it, sentiment of the words, safety — using a versioned prompt (prompts/classify_v1.md). In production that prompt runs on Claude Sonnet 5.5 via the Batch API; this submission's labels were produced by Claude through Claude Code with the identical prompt and audited by a person. Keyword rules run free as a fallback and a second opinion; where they disagree, the review lands in the queue above.
